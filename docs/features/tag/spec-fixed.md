## 기능 개요

노트에 태그를 추가하고 관리할 수 있다

## 기능 요구사항

- 노트에 태그를 추가할 수 있다
- 노트에 추가된 태그를 삭제할 수 있다
- 태그 목록을 노트 상세 화면(`NoteEditor`)에서 확인할 수 있다

## 데이터 구조

- `Note` 타입에 `tags: string[]` 필드를 추가한다.
- 별도 태그 테이블이나 관계 없이, 노트 객체 안에 배열로 그대로 저장한다 (json-server가 배열 필드를 기본 지원).
- `api/notes.ts`에 태그 전용 API 함수를 새로 만들지 않는다 — 기존 `updateNote`(PATCH)로 `tags`까지 함께 전송해서 처리한다.

## UI 패턴

- 태그 추가/삭제 UI는 `NoteEditor`에 배치한다 (별도 상세 뷰가 없고 `NoteEditor`가 노트 보기/편집을 겸함).
- `title`/`content`와 동일하게 `tags`도 `useState<string[]>` 로컬 상태로만 관리한다.
- 태그 입력창에서 추가/삭제해도 서버에는 즉시 반영하지 않는다. 화면의 "저장" 버튼을 눌러 `handleSave`가 실행될 때 `updateNote(id, { title, content, tags })`로 한 번에 반영한다.
- 태그는 칩(chip) 형태로 표시하고, 각 칩에 삭제(X) 버튼을 둔다.

## 입력값 검증 / 중복 처리

- 태그 입력값은 `trim()`으로 앞뒤 공백을 제거한다.
- trim 후 빈 문자열이면 추가를 거부한다 (`console.error`로 로깅, `alert` 사용 안 함 — 기존 에러 처리 컨벤션과 동일).
- 중복 판단은 대소문자를 구분하지 않는다 (`"React"`와 `"react"`는 같은 태그로 취급해 중복 추가를 막는다).
- 단, 저장되는 태그 값 자체는 사용자가 입력한 원문 그대로 유지한다 (임의로 소문자 변환하지 않음).

## 비고

- 태그는 문자열로 저장한다
- 중복 태그는 허용하지 않는다 (판단 기준: trim + 대소문자 무시 비교)
