📝 Notes 앱 — 구조 시각화

React 19 + TypeScript + Vite 노트 앱의 src/ 디렉토리를 정적 분석해서 그린 다이어그램입니다.

컴포넌트 간 의존성 관계와 상태(서버 상태 / 로컬 UI 상태)의 흐름을 각각 보여줍니다. src/ 구조가 바뀌면 mermaid-diagram 스킬을 다시 실행해서 갱신하세요.

1. 컴포넌트 의존성 그래프

src/ 각 파일의 import 관계를 계층(entry / App / context / components / api / types)으로 묶어서 표현했습니다. 실선은 일반 import, 점선은 useNotes()를 통한 Context 구독 관계입니다 (import 그래프만으로는 드러나지 않는 런타임 의존이라 별도 표시).

import (실선) useNotes() 구독 (점선)

2. 상태 흐름 다이어그램

서버 상태(NotesContext의 notes/isLoading/error)와 로컬 UI 상태(App.tsx의 선택/작성 모드, NoteEditor.tsx의 입력 폼)를 구분해서, 초기 로드 · 노트 선택 · 새 노트 작성 · 저장(CRUD) · 삭제 흐름을 표시했습니다. 낙관적 업데이트 없이 API 응답을 받은 뒤에만 setNotes가 갱신되는 구조를 반영합니다. 

flowchart TD
  subgraph server["🗄️ 서버 상태 — NotesContext (NotesProvider)"]
    notesState["notes: Note[]"]
    loadingState["isLoading"]
    errorState["error"]
  end

  subgraph appLocal["🧩 로컬 UI 상태 — App.tsx"]
    selectedId["selectedNoteId"]
    isCreatingState["isCreating"]
  end

  subgraph editorLocal["🧩 로컬 UI 상태 — NoteEditor.tsx"]
    formState["title / content"]
    isSavingState["isSaving"]
  end

  subgraph backend["json-server (localhost:3001)"]
    db[("db.json")]
  end

  mount(["앱 마운트"]) --> fetchNotes["api.fetchNotes()"]
  fetchNotes -->|"GET /notes"| db
  db -->|"응답"| notesState
  fetchNotes -.-> loadingState
  fetchNotes -.->|"실패시"| errorState

  clickNote(["노트 클릭 (NoteItem)"]) --> selectHandler["App.handleSelectNote"]
  selectHandler --> selectedId
  selectHandler -->|"isCreating = false"| isCreatingState
  selectedId -->|"props"| formState
  formState -.->|"useEffect deps=[selectedNoteId, isCreating]
⚠ notes만 갱신되면 재동기화 안 될 수 있음"| notesState

  clickNew(["+ 새 노트 클릭"]) --> newHandler["App.handleNewNote"]
  newHandler -->|"selectedNoteId = null"| selectedId
  newHandler -->|"isCreating = true"| isCreatingState

  clickSave(["저장 클릭"]) --> saveHandler["NoteEditor.handleSave"]
  saveHandler --> isSavingState
  saveHandler -->|"isCreating ? createNote : updateNote"| ctxAction["context.createNote / updateNote"]
  ctxAction -->|"POST / PATCH"| db
  db -->|"응답 Note"| notesState
  ctxAction -->|"await 완료 후"| doneHandler["onDone → App.handleDone"]
  doneHandler -->|"isCreating = false"| isCreatingState

  clickDelete(["삭제 클릭 (NoteItem)"]) --> deleteHandler["onDelete → context.deleteNote"]
  deleteHandler -->|"DELETE"| db
  deleteHandler -->|"성공시 filter"| notesState
